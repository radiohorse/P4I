# Week 08 - LEDs and Sensors

I moved from screen-based sketches to Arduino, starting with LEDs and basic sensor readings. I tried light, pressure and distance as inputs and watched how the values changed in the Serial Monitor.

| Activity | What I made |
| --- | --- |
| [8a - Light It Up](activity-8a_lightitup-01.ino/activity-8a_lightitup-01.ino.ino) | A blinking LED and a fading LED. |
| [8b - Light](Activity_8b_type_1/Activity_8b_type_1.ino) | Readings from a phototransistor. |
| [8b - Pressure](Activity_8b_type_2/Activity_8b_type_2.ino) | Readings from a force sensor. |
| [8b - Distance](Activity_8b_type_3/Activity_8b_type_3.ino) | Ultrasonic sensor readings converted to centimetres. |
