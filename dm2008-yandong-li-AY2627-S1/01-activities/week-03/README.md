# Week 03 - Arrays and Functions

I used an array to store colours and functions to draw repeating shapes. I also tried changing the drawing order to see how circles and triangles overlap.

| Activity | What I made |
| --- | --- |
| [3a - Array Sampler](activity-a/index.html) | A circle that grows or shrinks, with colours cycled from a palette. |
| [3b - One Function Wonder](activity-b/index.html) | Overlapping grids of peach circles and mint triangles. |

In 3a, press any key to cycle colours and hold S to show the palette. In 3b, hold 1 to bring the circles to the front.
